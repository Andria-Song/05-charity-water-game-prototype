# Purpose of File

This project was made for a Global Career Accelerator Class where students were tasked with creating a game that is strongly tied to the non-profit organization charity: water. 

My project in particular is a timing game where users must fill up as many jerry cans as possible within the time limit by hitting the green or yellow bars. 

# Technology Used

For this project, it mainly consists of event listeners and if-then statements. 

# What I learned

Through this project, I learned how to confidently write if-then statements, and I also learned how to tailor a game to an organization's brand guidelines.

# Challenges

There are challenges and limitations in the project. In particular the ramp up when users succeed in filling a bucket happens very quickly, and so that needs more fine-tuning so that it doesn't become a game of chance towards the end.
